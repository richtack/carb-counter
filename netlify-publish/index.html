This app needs your Supabase project to store food and logs.

  1. Create a free project at supabase.com.
  2. In the dashboard: SQL Editor → New query, paste supabase-setup.sql, click Run.
  3. Project Settings → API: copy your Project URL and anon public key.
  4. Open config.js, paste both values, save, and reload.
